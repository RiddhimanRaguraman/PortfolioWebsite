Azul Game Engine

C++ DirectX 11 SIMD Protocol Buffers

Overview

Azul Game Engine is a custom-built C++ game engine designed for high-performance 2D and 3D rendering. It features a robust asset pipeline, skeletal animation system with skinning support, and a flexible rendering architecture that wraps DirectX 11.

Key Features

High Performance Math

Built custom vector, matrix, and quaternion math libraries; achieved ~4× speedup using SIMD intrinsics (MMX, SSE).

Native File System

Implemented a high-performance file system using native OS APIs, including a custom archiving system for packed data storage.

Rendering Architecture

Developed a DirectX-based rendering engine with vertex buffers, frustum culling, multiple cameras, object transforms, and mesh loading.

Animation & Scene Graph

Designed a tree-based object hierarchy with scene graph and animation system support.

Offline Asset Converter

Created an offline converter to transform GLTF meshes into a custom runtime format using Google Protocol Buffers.
