C++ / Multithreading

Audio Engine

C++ Multithreading RAII Producer-Consumer

Overview

Engineered a real-time audio system to seamlessly stitch and play 23 raw WAVE files without artifacts. Designed a high-performance architecture to decouple file I/O from audio rendering for glitch-free playback.

Technical Implementation

25-Thread Architecture

Designed a sophisticated 25-thread architecture to decouple file I/O from audio rendering, ensuring zero-latency audio playback even under heavy load.

Producer–Consumer Model

Implemented a double-buffered Producer–Consumer model with circular queues for efficient inter-thread communication.

Safe Synchronization

Utilized mutexes and condition variables for safe thread synchronization (no spinlocks), ensuring robust resource management.

Resource Management

Applied RAII for robust resource and thread lifecycle management under real-time constraints.
