Custom Malloc & Free

C++ Low-level Performance

Overview

Designed and implemented a custom memory allocation and deallocation framework for performance-critical applications. This project focuses on low-level system-level memory management with a tight integration into C++.

Technical Highlights

Performance Optimization

Achieved ~2× faster performance compared to MSVC’s default allocator by optimizing memory layout and reducing fragmentation.

System Integration

Integrated tightly with C++ for low-level, system-level memory management, providing a robust and efficient alternative to standard allocation methods.

Allocation Strategies

Implemented custom strategies for memory pooling and block management to minimize overhead and maximize throughput.
