Clouds Rescue

Unity 2D C# ShaderLab Blender

Overview

Developed an educational 2D mobile game combining story-driven gameplay with math-based challenges for 10th-grade students. This project focuses on creating an engaging learning experience through interactive gameplay.

Key Features

Core Game Mechanics

Designed and implemented core game mechanics and dynamic level progression in C#, ensuring a balanced difficulty curve and engaging player experience.

Asset Integration

Integrated custom character assets created in Blender, ensuring a cohesive visual style and smooth animations.

Visual Effects

Built using Unity 2D with ShaderLab for rendering and high-quality visual effects, enhancing the overall game atmosphere.

Project Info

Platform Mobile (Android/iOS)
Target Audience 10th Grade Students
